# 补充材料 S1 · EBM「FT3,FT4 综合水平」z 值 → 临床实际反算表

> **为什么需要这份补充材料**:EBM 形状函数(F15/F23 等)横轴是**dev 集 z-score 标准化**后的「FT3,FT4 综合水平」,**"0"是各 landmark 自己 dev 集的均值,不是健康人的临床正常**。如果读者把模型零点误读为"健康临界值",**完全会读反临床意义**(尤其 1M 时,样本均值本身就是"轻度甲亢残留")。本附录给精确反算表 + 临床意义标注。

## 1. 大白话版(适合非统计读者)

EBM 横轴的「FT3,FT4 综合水平 z」 = "**这个病人在该 landmark 时点的 FT3、FT4 综合水平,比开发集(802 例)同时点平均值高/低多少个标准差**"。

- `z = 0` 不是健康人的"正常值",是 **dev 集那一时点的平均水平**
- `z > 0` = 比平均高 / `z < 0` = 比平均低
- **不同 landmark 的 z=0 对应不同临床状态**(下表): 1M 平均还在残留甲亢、3M/6M/12M 平均已落回正常区

健康人临床正常区(xlsx 表头给的):**FT3 2.43–6.01,FT4 9.01–19.05 pmol/L**。

## 2. 各 landmark dev 集实测分布

| Landmark | n(FT3) | FT3 均值 ± std | FT3 中位 | n(FT4) | FT4 均值 ± std | FT4 中位 | 平均临床状态 |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--|
| 1M | 718 | **9.10 ± 6.96** | 6.54 | 717 | **20.61 ± 11.18** | 17.62 | **轻度甲亢残留**(均值超 FT4 正常上限) |
| 3M | 666 | 6.75 ± 6.45 | 4.40 | 668 | 14.72 ± 10.52 | 11.59 | **正常 FT4 范围**(均值在正常区中段) |

**关键观察**:
- **1M 时样本均值 = 治疗反应慢/残留甲亢**(FT3 9.1 远超正常上限 6.0,FT4 20.6 略超正常上限 19.05);
- **3M 起样本均值已落回正常区**,反映多数人在 3 个月内对 RAI 已起反应;
- **6M 与 12M 均值几乎重合**,说明 6 个月后病情已分流到三态(甲亢残留 / 正常 / 甲减),整体均值稳定;
- **每个 landmark 的 z=0 含义不同**,所以**直接比较两个 landmark 的 z 值是错的**(只能各自 landmark 内部比较)。

## 3. 反算表(逐 landmark)

`FT3 实际值 = μ(FT3) + (z/√2)·σ(FT3)`,FT4 同。

## 4. 临床转化要点(避免误读)

1. **"FT3,FT4 综合水平 z = 0"不是"健康正常"**,是"该时点 dev 群体平均水平"。1M 时这个平均水平本身就是甲亢残留(治疗刚开始一个月,多数人还在恢复期)。
2. **形状函数曲线的"零点参考"(F15 在 z ≈ −0.7)**:不是临床安全阈值,是 EBM cyclic boosting 内部选的 baseline。临床转化**看相对趋势**(单调上升 = 激素越高越危险)+ **决策曲线(DCA)给的工作阈值**,而非把形状函数零点当成安全/危险分界。
3. **跨 landmark 的 z 不可直接比**:每个时点用自己的 dev μ/σ 标准化;1M 的 z = 0 ≈ FT4 20.6,6M 的 z = 0 ≈ FT4 14.9 — 实际值差 5.7 pmol/L,但都是各自时点的"平均水平"。
4. **如要外部验证或临床部署**:必须**冻结 dev μ/σ**(已在 atlas 脚本里实现),新病人按这个 μ/σ 算 z 才能套用 EBM 形状函数。

## 5. 代码与可复现

反算表由本文件同目录的脚本片段产出(`module2_v2_ebm_atlas.py` 中 `_zfit()` 与 `build_feats_at_L()` 是构造源;反算公式 `μ + (z/√2)·σ` 直接由公式逆推)。

```python
# 复现这张表 — 任意 landmark L:
import pandas as pd, numpy as np
m1 = pd.read_csv("results/module1_baseline_ml_benchmark/tables/module1_frozen_feature_matrix.csv")
dev_ids = m1[m1["Split"]=="Development"]["Episode_Index"].values
s2 = pd.read_csv("results/stage2_mh_h6h12_cjk/tables/stage2_long_table.csv", low_memory=False)
s2_dev = s2[s2["Treatment_Index"].isin(dev_ids)]
for L in (1, 3, 6, 12):
    ft3 = pd.to_numeric(s2_dev[f"FT3_{L}M"], errors="coerce").dropna()
    ft4 = pd.to_numeric(s2_dev[f"FT4_{L}M"], errors="coerce").dropna()
    print(f"{L}M  μ_FT3={ft3.mean():.2f} σ_FT3={ft3.std():.2f}  μ_FT4={ft4.mean():.2f} σ_FT4={ft4.std():.2f}")
    for z in (-2, -1, -0.7, 0, 0.5, 1, 3):
        z_each = z / np.sqrt(2)
        print(f"  z={z:+.1f}  FT3≈{ft3.mean() + z_each*ft3.std():.1f}  FT4≈{ft4.mean() + z_each*ft4.std():.1f}")
```
