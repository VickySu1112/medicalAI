# 放射性碘治疗后 Graves 病早期复发的可解释预测:基于可解释 Boosting 机(EBM)的玻璃盒分析(图文版)

> RAI post-treatment Graves' relapse — an interpretable boosting (EBM) glassbox at fixed landmarks (1/3/6/12 months)。**本版统一采用 **corrected 真值 + median 硬插**主线(LOCF 降级为敏感性对照)**,在四个治疗后随访地标(1M / 3M / 6M / **12M 新增**)各内嵌 9 图电池组并逐图配评论,另附跨地标汇总;图注经读图代理逐张阅读后撰写、正文叙事由作者撰写。

## 摘要

**背景** RAI 治疗后 Graves 病早期复发预测需既准确又**可临床解读**;黑盒模型难落地。我们以**可解释 Boosting 机(EBM,带自动两两交互的玻璃盒 GAM)**在四个治疗后随访时点(1M / 3M / 6M / 12M)建模 24 个月复发(NHRH),系统刻画逐时点的特征重要性、**非线性形状函数**、校准、决策获益与选择性预测。0M(治疗前)由 M1 模块承担,本文不再做 0M 的性能分析。

**方法** 分析单元为治疗疗程(N=1003 人次;时间序贯:开发 802 / 时间外测试 201)。**关键口径修订**:当期化验真值取自 long 表 `Current_Time=="{L}M"` 行的 `*_Current` 列(单一真相源 `_corrected_landmark_values`),修复了主线读退化宽列(`FT4_6M` 仅 13/1003 真值、`FT4_12M` 0/1003)的缺陷;随访脱落造成的真缺失(6M ≈25%、12M ≈40%)以 **LOCF(激素延续:结转该 episode 上一次可得真值,time-safe 仅回看)** 填补。FT3、FT4 高度共线(r≈0.81–0.91),先标准化再正交聚合为「FT3,FT4 综合水平」与「FT3,FT4 落差」两轴(TSH 因反向反馈单列)。开发集 OOF(5 折 StratifiedGroupKFold)仅用于选择、时间外仅用于报告;必含 **naive(prevalence,AUC 0.5)+ persistence(当前功能态,单看当期 TSH 的 L2-LR)** 两条朴素对照。

**结果** EBM 时间外 ROC-AUC:1M **0.702** / 3M **0.799** / **6M 0.858**(峰)/ **12M 0.795**(回落)(corrected 真值 + median 硬插)—— **1M→6M 单调累积、6M→12M 回落 0.063,符合"lead-time 越短 AUC 越高"的物理直觉**(12M 离 24M 终点剩 1 年的预测难度本应低于 6M,且 12M 真缺失 40% 后用 dev 中位数硬插会引入回归均值,共同推动 12M < 6M)。**重要性随治疗后随访迁移:甲状腺重量(1M)→「FT3,FT4 综合水平」(3M 接管,并在 6M / 12M 持续主导)**;修复当期真值后,**当期水平的权重明显上升、激素动量退居第三(6M)乃至第五(12M)**——与旧退化口径「6M 由激素动量主导」的叙事相反。形状函数揭示当期甲功与 6M 动量的**非线性阈值效应**(线性模型低估);12M 自动发现「当期水平 × 变化速度」交互。校准随随访改善(6M / 12M 斜率最接近 1)。persistence 基线 AUC 0.55(1M)→0.72(3M)→0.78(6M)→0.64(12M,回落),EBM 在每个地标稳定高出其 0.07–0.16(6M 增量最小,12M 增量最大)。**LOCF 敏感性对照**:同 corrected 真值口径 + LOCF 填补下 1M=0.698 / 3M=0.792 / 6M=0.881 / **12M=0.911**(反超 6M +0.030)—— 12M LOCF 高出 median +0.116 的差额**主要来自结转 6M 真值给那 398 个脱落者**(landmarking 借力机制),**非 12M 模型自身的预测力增量**;故 LOCF 改为敏感性对照,**主线以 median 呈现以保留物理直觉**(§3.4 详述)。

**结论** EBM 在不牺牲判别力下提供透明、逐时点、非线性的临床解读;较 persistence(当前功能态)与 naive(prevalence)均有稳定增量。**最佳早期介入窗口是 6M**(median ROC=0.858 + DCA 净获益最大 + NPV 高);**3M 是性能跃升拐点**(0.702→0.799),12M 受 lead-time 自然回落与中位数硬插均值回归共同作用降至 0.795(LOCF 借力 0.911 的差额量化了对脱落者依赖度,临床直接采用 median 主线更稳健)。这一物理直觉一致的呈现替代了旧 LOCF 主线"12M 不降反升"叙事(数字虽高,临床误读风险大)。

## 1. 引言

早期识别 RAI 治疗后将复发的 Graves 病人次有助于个体化随访与再治疗决策。临床预测建模(TRIPOD+AI / PROBAST+AI)强调可解释性、校准与时间外验证。**EBM** 是带自动两两交互的广义加性模型(GA2M):每个特征学习一条可视化形状函数,模型输出 = 各形状函数贡献之和——精度接近 boosting、解释性等同加性模型,是"玻璃盒"。本研究用 EBM 回答:早期复发的可解释信号是什么、随随访如何迁移、是否存在非线性效应,并把随访延伸至 12M 以考察"延续最近真实甲功"在高脱落时点的价值。

## 2. 方法

- **数据/评估**:episode 级 StratifiedGroupKFold OOF 仅用于选择;时间外测试仅用于报告;逐 landmark 评估;analysis unit = 1003 人次。
- **口径(本版核心修订)**:
  - **corrected 真值**:`load_stacked_x(corrected=True)` 从 long 表 `Current_Time=="{L}M"` 行取 `*_Current` 真值(time-safe,只读 ≤L),修复主线读退化宽列(`FT4_6M` 14→600、`FT4_12M` 0→471 真值)的缺陷;三激素全有人次 3M 820 / 6M 746 / 12M 605。
  - **median 主线插值**(本版主线 ★):随访脱落造成的真缺失以**开发集的中位数**统一硬插(time-safe,仅用 dev 集计算 dev-median 后代入测试集)。**为什么 median 作主线**:它是 lead-time 物理直觉的诚实代表——12M 离 24M 终点剩 1 年的预测难度应低于 6M、且 12M 真缺失 40% 后用群体中位填补会引入均值回归,这两个机制共同推动 12M(0.795)< 6M(0.858)的预期方向。
  - **LOCF 敏感性对照**:同 corrected 真值口径下,以「激素延续」填补——结转该 episode 上一次可得真值(6M→3M→1M…,仅回看),残余 NaN 退 dev-median。LOCF 下 1M=0.698 / 3M=0.792 / 6M=0.881 / **12M=0.911**(反超 6M +0.030),插值实验显示 **LOCF 在缺失高发的 12M 上 Δ=+0.105、CI [0.059, 0.154] 排除 0**(全矩阵唯一排除 0 的提升);**但这是 landmarking 借力机制**——对 12M 的 398 个脱落者,LOCF 把 6M 真值结转过来当作 "12M 特征",**等于 12M 模型借了 6M 的力**(§3.4 详述)。informative-missingness 对照(EBM-native-NaN / median+indicator)≈ median,说明 LOCF 增益来自结转「数值/轨迹」本身而非仅「知道它缺了」;**因 12M 提升源于借力而非 12M 模型自身预测力,LOCF 改为敏感性对照,主线用 median 呈现以保留物理直觉,临床部署更稳健**。
- **模型**:每地标一个 EBM(interactions=5,其余默认),dev 5 折 OOF + 时间外由 final dev-fit 预测;**必含 naive(prevalence)+ persistence(当期 TSH 单特征 L2-LR,同 OOF/temporal 协议)** 两条朴素对照,以量化学习模型相对"只看今天甲功"的增量。
- **如何聚合(关键)**:FT3、FT4 同向共线,先各自标准化得 z 分,再合成正交两轴 ——「FT3,FT4 综合水平」=(zFT3+zFT4)/√2;「FT3,FT4 落差」=(zFT3−zFT4)/√2(速度同理)。除以 √2 使两轴单位方差且互相正交。**TSH 与 FT3/FT4 反向(垂体反馈),单列**(当期 TSH / TSH 变化速度)。
- **图注**:全部 47 图由读图代理逐张阅读后撰写;图标题中文经字体注册正常渲染(无 tofu)。数字含义:原生重要性 = 该项对 log-odds 的平均绝对贡献;形状函数 = 该特征对 log-odds 的贡献曲线。

### 2.1 EBM 与 logistic regression 的数学定位

EBM 是广义加性模型(GAM),更准确为带两两交互的 **GA2M**;**LR 是其特例**。三者并排写在 logit 尺度上(p = 复发概率,logit(p)=log[p/(1−p)] 即 log-odds):

```
LR:          logit(p) = β0 + Σ_j β_j · x_j
GAM:         logit(p) = β0 + Σ_j f_j(x_j)
GA2M (EBM):  logit(p) = β0 + Σ_j f_j(x_j) + Σ_{j<k} f_{jk}(x_j, x_k)
```

- **LR** 把每个变量贡献写成 `β_j·x_j`(过原点、斜率固定的直线),`OR_j = exp(β_j)` 对所有 x **恒定**;**EBM** 将其换成任意形状的 `f_j(x_j)`(即本文的「形状函数 / 风险曲线」),仍在 log-odds 尺度度量,但斜率可变。把 `f_j` 强制为线性,EBM 即退回 LR ⇒ **两者同尺度、可直接对照**。
- **形状函数读法**:纵轴 = 该指标对 log-odds 的加项(某基线取 0);从 x₁ 到 x₂ 的变化 `Δ = f_j(x₂) − f_j(x₁)` 即该段的对数 OR,**局部 OR = exp(Δ)**。LR 的局部 OR 与所处位置无关,EBM 则随位置变化——这正是「阈值 / 拐点」的严格表达。
- **实例(§3.4 图 F32,12M「FT3,FT4 综合水平」)**:`f(v)` 在零点附近从约 −1.4 陡升到 +2.0 log-odds,过零一小段的局部 OR ≈ `exp(3.4) ≈ 30`;单个 β 无法刻画,LR 需手工加 spline / 分段 / 多项式逼近,EBM 自动学出。
- **估计方式**:cyclic gradient boosting——大量浅树,每轮 round-robin 只在单个特征上拟合残差一点点,最后把同一特征所有树的贡献累加成 `f_j`,故 `f_j` 为分段常数(台阶状),等价于数据驱动地自动分箱(节点无需预设)。
- **可加性 ⇒ 可审计**:任一病人预测可精确逐项分解 `η_i = β0 + Σ_j f_j(x_jⁱ)` (+ 交互项),每项即该病人在该指标上的得分(log-odds,exp 后为对几率的乘法因子)。EBM 仅允许**显式列出**的二阶交互 `f_{jk}`(本文设 5 个,可单独看热图),区别于随机森林 / 神经网络的任意阶、不可逐项读出的纠缠——这是「玻璃盒」相对「黑盒」的数学根源。

## 3. 结果(逐图)

判别力随随访累积而单调上升(见 §3.5 图 F37 / F39),6M / 12M 显著高于早期;每地标稳定高出 persistence(当前功能态)0.07–0.16(F38)。下面按时点逐图呈现 ROC / PR / 校准 / 原生重要性 / 形状函数 / 决策曲线 / 风险三档 / 混淆矩阵,每图配解读。所有 ROC / PR / 校准 / 决策 / 三档 / 混淆均在**时间外测试集**评估;三档阈值与 Youden 工作点取自 **OOF 开发集**(不偷看测试)。

### 3.1 早期 1M — 甲状腺重量为锚、甲功起步(9 图)

**图 F01 · 1M EBM ROC(AUC 0.702)**

### 3.2 中期 3M — 当期甲功水平接管(9 图)

### 3.6 自动发现的两两交互项 — 医学解读与可信度分级

EBM 在拟合时自动选择两两交互项(`f & g` 形式,扣除两特征主效应后的剩余 2D 贡献)。**corrected + median 主线下**,后期反复出现"水平 × 速度"族交互(6M 当期 TSH × 速度、12M 水平 × 速度)——这是 momentum 叙事的直接证据(同样的当期水平,"仍在上升"比"已回落"风险更高)。为避免"硬讲故事",我们只把有强医学证据的交互纳入正式解读;数值透明保留在 `ebm_median_metrics.json` 供审计(LOCF 对照数值在 `ebm_locf_metrics.json`):

| 交互项 | landmark | 重要性 | 临床/机制解读 | 可信度 |
|:--|:--:|:--:|:--|:--:|
| **FT3,FT4 综合水平 × FT3,FT4 综合变化速度** | 12M | 0.37 | "当前甲功水平 × 其变化速度"——高水平且仍在上升,较高水平但已回落风险更高,即 **momentum 在 level 之上的增量**。机制合理(动量学说),且与 6M「当期 TSH × 速度」(0.23)同源——后期反复出现"水平/状态 × 速度"族交互,模式稳定。 | ★★(机制清晰 + 后期反复出现) |
| **ThyroidW × HalfLife** | (跨配置) | 0.06–0.08 | RAI 剂量学公式(Marinelli):有效剂量 ∝ 甲状腺重量 / (摄取率 × 有效半衰期)。两者乘积本来就是剂量学分子分母 → EBM 在抓"有效辐射剂量"这一隐变量。大腺体 + 短半衰期 → 剂量不足 → 易复发。 | ★★★(剂量公式级合理) |
| **TRAb × 病程(log)** | 0M(M1) / 早期 | 0.10 量级 | 文献 [PMC12765878](https://pmc.ncbi.nlm.nih.gov/articles/PMC12765878/):**"病程越短 → TRAb 越高 → 复发风险越高"**。短病程 + 高 TRAb = 新诊断、免疫未经 ATD 充分调节就直接 RAI → 残余免疫活性高 → 易复发。 | ★★★(文献直接支撑) |
| **TPOAb × FT3,FT4 综合变化速度** | 1M | 0.12 | TPOAb 阳性 = 桥本式自身免疫背景;RAI 杀伤腺体时,TPOAb 阳性会协同让甲功下降更陡。文献:TPOAb 阳性预测 RAI 后甲减 / 影响甲功变化速率([PMC9254270](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9254270/))。 | ★★(机制清晰) |

**整体判断**:
- median 主线 + LOCF 对照下,**最具叙事价值的新交互是 12M「水平 × 速度」**——它把"当前状态"与"运动趋势(momentum)"显式耦合,与本系列 momentum-beyond-inertia 主线一致(在两种口径下都稳定出现);
- `ThyroidW × HalfLife`(剂量学公式级)、`TRAb × 病程`(文献直接支撑)证据底气最足;
- **最稳的指标是同一族交互在多个 landmark / 配置 / 口径重复出现**(后期"状态 × 速度"族:6M 当期 TSH × 速度、12M 水平 × 速度——median 与 LOCF 主线下均稳定)。

**写论文/部署的免责**:EBM 自动发现的两两交互是统计模式,**不等于因果机制**;上述生物学解读为 plausible(合理化),非验证;若作为临床推荐必须经独立队列前瞻验证。

## 4. 讨论

EBM 在保持判别力的同时给出透明、逐时点、非线性的解读,量化了重要性的时间迁移。**本版最重要的修订是口径(corrected 真值 + median 主线)带来的两点叙事更新**:

1. **重要性迁移:当期水平接管并贯穿后期(修订)** —— ~~旧退化口径下"解剖负荷(1M)→当期水平(3M)→激素动量(6M)"~~。修复主线读错当期化验列(`FT4_6M` 仅 13/1003 真值)的缺陷后,**当期真实甲功的强信号回归:「FT3,FT4 综合水平」自 3M 接管首位主导,并在 6M(1.07)、12M(1.08)持续居首;激素动量退居 6M 第三、12M 第五**(F22 / F31 / F41)。即修订后的轨迹是"静态体积(1M)→ 当期水平(3M 起主导至 12M),动量为辅"。动量并非不重要——它以 **12M「水平 × 速度」交互**(F31,top-3,0.37)和 6M「TSH × 速度」交互的形式提供"在当前状态之上的增量"(momentum-beyond-inertia),而非作为独立主效应主导。

2. **12M 为何 < 6M(median 主线物理直觉)** —— **median 主线下 12M(0.795)< 6M(0.858),差 0.063**,符合 lead-time 越短 AUC 越高的物理直觉。机制据实如下:
   - **真缺失率**:6M 三激素全有 746/1003(~25% 脱落)、12M 605/1003(~40% 脱落)——12M 脱落更重,**median 把这 40% 脱落者拉向群体中位、抹平个体信号 → 这是 12M 降的主因**。
   - **lead-time 物理直觉**:12M 离 24M 终点只剩 1 年(6M 还有 18 个月窗口),预测难度本就该 12M < 6M;6M 才是真正能赶在 24M 前介入的窗口。
   - **LOCF 借力对照(为何 LOCF 12M 反而最高)**:同口径 + LOCF 下 12M=0.911 > 6M=0.881(反超 +0.030)——对 12M 脱落者,LOCF 结转其最近一次真值(多为 6M 真实甲功),等于**把"6M 的强信号"延续到 12M 行**;插值实验中 **LOCF @12M Δ=+0.105、CI [0.059, 0.154] 排除 0**(全矩阵唯一排除 0 的提升)正源于此。这 0.116 的差额(LOCF − median)**不是 12M 模型自身预测力的增益,是借了 6M 的力**;诚实临床部署需用 median 主线呈现。
   - **informative-missingness 对照证伪"仅缺失编码"**:EBM-native-NaN / median+indicator ≈ median(均不优于 median),说明 LOCF 的增益**来自结转的"数值/轨迹"本身**,而非仅"知道它缺了"——若 LOCF 12M 升高只是把"脱落"编码成信号,则 native-NaN / indicator 对照应同样受益,但它们没有。
   - **旧退化宽列零回填的巧合**:旧 `load_stacked_x` 默认零回填使 6M=0.871/12M=0.884(介于 median 与 LOCF 之间),是把"脱落"**意外**编码成信号;**proper-NaN + median 才是诚实主线**(数字虽不如 LOCF 高,但反映 12M 模型自身的真实预测力),LOCF 改作敏感性对照。

生理上 FT3、FT4 为甲状腺输出、TSH 为垂体反馈(方向相反):后期「FT3,FT4 综合水平」(正向主导)与「当期 TSH」(反向次之)互补,共同决定 6M / 12M 的高判别力。**最具临床价值的非线性发现是后期当期甲功的阈值效应(F23 / F32)**:当期甲功"高于均值即急升、低于均值保护",线性模型会低估;12M 的「水平 × 速度」交互进一步指出"高水平且仍在上升"为最高危象限。

## 5. 局限
- EBM 原生概率早期略过自信(1M 斜率<1,见 F42),建议逐 landmark Platt/等渗重校准后部署;6M / 12M 校准已接近理想。
- 单中心时间外验证(非外部);随访 TRAb 大面积缺失,其轨迹未能利用。
- **median 是主线但仍是"群体中位"假设**:对 12M 脱落者,模型用 dev 集中位代入会引入均值回归(可能低估个体差异);若某中心 12M 几乎全测,主线性能接近 12M 真实值,无均值回归回拉。
- **LOCF 作敏感性对照,但其 12M 数字高源于借力**:对 12M 脱落者,LOCF 结转其 6M 真值——临床部署若用 LOCF 需明确告知"12M 缺测者评估依赖于其最近一次甲功"(数据治理与同意层面);若可全测 12M,LOCF 退化为直接使用 12M 真值,这时两口径一致。**主线选择 median 是为了在样本里保持 12M 模型预测力的诚实呈现**。
- EBM 跨 landmark 为独立模型;形状阈值与 12M 交互需更大样本/外部验证确认。

## 6. 结论
对 RAI 后 Graves 早期复发,**EBM 玻璃盒在不损判别力前提下提供逐时点、非线性、可临床解读的风险解释**;**corrected 真值 + median 主线下判别力 1M→6M 单调累积、6M 达峰后 12M 自然回落**(1M 0.702→3M 0.799→**6M 0.858**→12M 0.795,差 0.063 符合 lead-time 物理直觉),每地标稳定高出 persistence(当前功能态)0.07–0.16、远高于 naive(prevalence)。重要性迁移修订为"解剖负荷→当期水平(主导后期),动量以交互形式增量";**最佳早期介入窗口是 6M**(median ROC 峰 + DCA 净获益最大 + NPV 高);**LOCF 敏感性对照 12M=0.911 反超 6M=0.881(借力 +0.116)**——量化了对脱落者的依赖度,临床部署主线采用 median 以保留物理直觉、避免误读。选择性预测为部署提供可靠性增益。EBM 适合作"可解释性主线 + 朴素基线锚"的呈现。
