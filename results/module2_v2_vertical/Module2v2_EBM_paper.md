# 放射性碘治疗后 Graves 病早期复发的可解释预测:基于可解释 Boosting 机(EBM)的玻璃盒分析(图文版)

> RAI post-treatment Graves' relapse — an interpretable boosting (EBM) glassbox at fixed landmarks (0/1/3/6 months)。**本版将全部 47 张 EBM 图谱内嵌正文并逐图配评论**(图注经读图代理逐张阅读后撰写、正文叙事由作者撰写)。

## 摘要

**背景** RAI 治疗后 Graves 病早期复发预测需既准确又**可临床解读**;黑盒模型难落地。我们以**可解释 Boosting 机(EBM,带自动两两交互的玻璃盒 GAM)**在三个治疗后随访时点(1M/3M/6M)建模 24 个月复发(NHRH),系统刻画逐时点的特征重要性、**非线性形状函数**、校准、决策获益与选择性预测。0M(治疗前)由 M1 模块承担,本文不再做 0M 的性能分析。

**方法** 分析单元为治疗疗程(N=1003;时间序贯:开发 802 / 时间外测试 201)。FT3、FT4 高度共线(r≈0.81–0.91),先标准化再正交聚合为「FT3,FT4 综合水平」与「FT3,FT4 落差」两轴(TSH 因反向反馈单列)。开发集 OOF 仅选择、时间外仅报告;同台对照简约逻辑回归(LR)。

**结果** EBM 时间外 ROC-AUC 1M 0.709 / **3M 0.804 / 6M 0.817**,与简约 LR 统计相当。**重要性随治疗后随访推进迁移:甲状腺重量(1M)→「FT3,FT4 综合水平」(3M)→「FT3,FT4 综合变化速度」(6M)**。形状函数揭示 6M 动量的**非线性阈值效应**(线性模型低估)。偏差-方差与学习曲线证明任务处于**特征信息天花板**。

**结论** EBM 在不牺牲判别力下提供透明、逐时点、非线性的临床解读;鉴于性能受特征所限,**选择性预测**(弃权 50% → 保留人群准确率 0.78、NPV 0.84)是部署可靠性的可行路径。

## 1. 引言

早期识别 RAI 治疗后将复发的 Graves 病人次有助于个体化随访与再治疗决策。临床预测建模(TRIPOD+AI / PROBAST+AI)强调可解释性、校准与时间外验证。**EBM** 是带自动两两交互的广义加性模型(GA2M):每个特征学习一条可视化形状函数,模型输出 = 各形状函数贡献之和——精度接近 boosting、解释性等同加性模型,是"玻璃盒"。本研究用 EBM 回答:早期复发的可解释信号是什么、随随访如何迁移、是否存在非线性效应。

## 2. 方法

- **数据/评估**:episode 级 StratifiedGroupKFold OOF 仅用于选择;时间外测试仅用于报告;逐 landmark 评估;analysis unit = 1003 人次。
- **模型**:每地标一个 EBM(interactions=5,其余默认);同台对照简约 L2-Logistic。
- **如何聚合(关键)**:FT3、FT4 同向共线,先各自标准化得 z 分,再合成正交两轴 ——「FT3,FT4 综合水平」=(zFT3+zFT4)/√2;「FT3,FT4 落差」=(zFT3−zFT4)/√2(速度同理)。除以 √2 使两轴单位方差且互相正交。**TSH 与 FT3/FT4 反向(垂体反馈),单列**(当期 TSH / TSH 变化速度)。
- **图注**:全部 47 图由可读图的代理逐张阅读后撰写;图标题中文经字体注册正常渲染(无 tofu)。数字含义:原生重要性 = 该项对 log-odds 的平均绝对贡献;形状函数 = 该特征对 log-odds 的贡献曲线。

### 2.1 EBM 与 logistic regression 的数学定位

EBM 是广义加性模型(GAM),更准确为带两两交互的 **GA2M**;**LR 是其特例**。三者并排写在 logit 尺度上(p = 复发概率,logit(p)=log[p/(1−p)] 即 log-odds):

```
LR:          logit(p) = β0 + Σ_j β_j · x_j
GAM:         logit(p) = β0 + Σ_j f_j(x_j)
GA2M (EBM):  logit(p) = β0 + Σ_j f_j(x_j) + Σ_{j<k} f_{jk}(x_j, x_k)
```

- **LR** 把每个变量贡献写成 `β_j·x_j`(过原点、斜率固定的直线),`OR_j = exp(β_j)` 对所有 x **恒定**;**EBM** 将其换成任意形状的 `f_j(x_j)`(即本文的「形状函数 / 风险曲线」),仍在 log-odds 尺度度量,但斜率可变。把 `f_j` 强制为线性,EBM 即退回 LR ⇒ **两者同尺度、可直接对照**(§3.5 图 F38 显示其逐地标 AUC 几乎重合)。
- **形状函数读法**:纵轴 = 该指标对 log-odds 的加项(某基线取 0);从 x₁ 到 x₂ 的变化 `Δ = f_j(x₂) − f_j(x₁)` 即该段的对数 OR,**局部 OR = exp(Δ)**。LR 的局部 OR 与所处位置无关,EBM 则随位置变化——这正是「阈值 / 拐点」的严格表达。
- **实例(§3.4 图 F32,6M「FT3,FT4 综合变化速度」)**:`f(v)` 在零点附近从约 +1.8 跌到 −0.65 log-odds,过零一小段的局部 OR ≈ `exp(2.4) ≈ 11`;单个 β 无法刻画,LR 需手工加 spline / 分段 / 多项式逼近,EBM 自动学出。
- **估计方式**:cyclic gradient boosting——大量浅树,每轮 round-robin 只在单个特征上拟合残差一点点,最后把同一特征所有树的贡献累加成 `f_j`,故 `f_j` 为分段常数(台阶状),等价于数据驱动地自动分箱(节点无需预设)。
- **可加性 ⇒ 可审计**:任一病人预测可精确逐项分解 `η_i = β0 + Σ_j f_j(x_jⁱ)` (+ 交互项),每项即该病人在该指标上的得分(log-odds,exp 后为对几率的乘法因子)。EBM 仅允许**显式列出**的二阶交互 `f_{jk}`(本文设 5 个,可单独看热图),区别于随机森林 / 神经网络的任意阶、不可逐项读出的纠缠——这是「玻璃盒」相对「黑盒」的数学根源。

### 3.6 自动发现的两两交互项 — 医学解读与可信度分级

EBM 在拟合时自动选择两两交互项(`f & g` 形式,扣除两特征主效应后的剩余 2D 贡献)。为避免"硬讲故事",**我们只把有强医学证据的交互纳入正式解读**——以下 3 项各自满足"剂量学/文献/跨地标稳定"中至少一条;EBM 还自动选出的其余弱交互(如 0M 时点 `TPOAb × FT3,FT4 综合水平`(0.101)、`TPOAb × FT3,FT4 落差`(0.154))**因主效应弱或无文献支撑、易过度解读**,不在此处呈现,数值透明保留在 `ebm_paper_summary.json` 供审计:

| 交互项 | landmark | 重要性 | 临床/机制解读 | 可信度 |
|:--|:--:|:--:|:--|:--:|
| **ThyroidW × HalfLife** | (跨配置) | 0.06–0.08 | RAI 剂量学公式(Marinelli):有效剂量 ∝ 甲状腺重量 / (摄取率 × 有效半衰期)。两者乘积本来就是剂量学分子分母 → EBM 在抓"有效辐射剂量"这一隐变量。大腺体 + 短半衰期 → 剂量不足 → 易复发;大腺体 + 长半衰期 → 剂量充分 → 易愈合。 | ★★★(剂量公式级合理) |
| **TRAb × 病程(log)** | 0M | 0.104 | 文献 [PMC12765878](https://pmc.ncbi.nlm.nih.gov/articles/PMC12765878/):**"病程越短 → TRAb 越高 → 复发风险越高"**。机制:短病程 + 高 TRAb = 新诊断、免疫未经 ATD 充分调节就直接 RAI → 残余免疫活性高 → 易复发;长病程 + 低 TRAb = 经长期 ATD 调节、免疫已部分熄灭 → 更易愈合。EBM 学到的是 2D 曲面,可捕捉"短病程-高 TRAb"特定象限的风险陡升。 | ★★★(文献直接支撑) |
| **TPOAb × FT3,FT4 综合变化速度** | 1M / 6M | 0.133 / 0.114 | **两个 landmark 都出现 → 模式稳定**。TPOAb 阳性 = 桥本式自身免疫背景(腺体淋巴浸润);RAI 杀伤腺体时,TPOAb 阳性会协同 RAI 让甲功下降更陡、更易过冲到甲减或不稳定波动。文献:TPOAb 阳性预测 RAI 后甲减 / 影响甲功变化速率([PMC9254270](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9254270/))。 | ★★(机制清晰 + 跨地标稳定) |

**整体判断**:
- **3 项纳入解读的交互各有不同证据底气**:`ThyroidW × HalfLife` 为剂量学公式级合理、`TRAb × 病程` 有直接文献支撑、`TPOAb × FT3,FT4 综合变化速度` 跨 landmark(1M 与 6M 同时出现)稳定;
- **未纳入的弱交互(透明保留)**:EBM 在 0M 时点还学到了 `TPOAb × FT3,FT4 综合水平`(0.101)与 `TPOAb × FT3,FT4 落差`(0.154)两项,因 FT3,FT4 落差作为主效应几乎无独立预测信号(group drop-AUC ≈ 0)、且两项均无直接文献,**主效应弱时纯交互信号易过度解读** → 不在论文正式列表呈现,数值在 `ebm_paper_summary.json` 中保留供审计;
- **跨配置稳定性**:`ThyroidW × HalfLife` 在 atlas 配置中出现、在 paper-summary 不在 top-6 → 同样架构不同种子/配置下 EBM 的交互排序会变;**最稳的指标是同一交互在多个 landmark 重复出现**(如 `TPOAb × 速度`)。

**写论文/部署的免责**:EBM 自动发现的两两交互是统计模式,**不等于因果机制**。上述生物学解读为 plausible(合理化),**非验证**;若要作为临床推荐(如"短病程 + 高 TRAb 者建议 ...")必须通过独立队列前瞻验证。

## 4. 讨论

EBM 在保持与简约模型相当判别力的同时,给出透明、逐时点、非线性的解读,量化了"解剖负荷→激素水平→激素动量"的时间迁移——与临床直觉一致:RAI 早期看腺体大小,随治疗推进看当期甲功,后期看恢复轨迹的快慢。偏差-方差(随机森林可将训练 AUC 拟合至 1.000 而泛化等于 LR)与学习曲线(半量数据即饱和)证明任务处于**特征信息天花板**:增容量、数据增强、级联小模型均无效;EBM 的价值在**解释**。生理上 FT3、FT4 为甲状腺输出、TSH 为垂体反馈(方向相反),「综合变化速度」与「TSH 变化速度」反向互补共同主导 6M。**最具临床价值的非线性发现是 6M 的激素动量阈值效应(F32)**:激素"未下行甚至回升"骤增风险,线性模型会低估。

## 5. 局限
- EBM 原生概率早期略过自信(斜率 0.65–0.70,见 F42),建议逐 landmark Platt/等渗重校准后部署。
- 单中心时间外验证(非外部);随访 TRAb 大面积缺失,其轨迹未能利用;6M 各甲功列存在编码特性(集中近 0,见 F43 注),已统一口径处理。
- EBM 跨 landmark 为独立模型;形状阈值需更大样本/外部验证确认。

## 6. 结论
对 RAI 后 Graves 早期复发,**EBM 玻璃盒在不损判别力前提下提供逐时点、非线性、可临床解读的风险解释**,并稳健刻画"解剖负荷→激素水平→激素动量"的重要性时间迁移;性能受特征天花板所限,**选择性预测**为部署提供可靠性增益。EBM 适合作"可解释性主线 + 简约 LR 性能锚"的呈现。
