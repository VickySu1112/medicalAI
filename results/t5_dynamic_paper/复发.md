# 3M 表征增强的四分支动态复发预警模型

## 摘要

本报告聚焦一个动态复发模型：在每个随访 landmark `t`，仅使用 `t` 及之前可得信息，预测下一时间窗 `t -> t+1` 内是否复发。当前主模型记为 **4branch**，结构为 **static / local / global / z3M 四分支 + 单一 hazard head**。

在固定阈值 `0.785` 下，temporal test 达到 AUC `0.842`、PR-AUC `0.320`、F1 `0.347`、Recall `0.610`、Specificity `0.835`。该阈值锁定自开发流程中的 train-fit F1 选择，并补充 validation/test threshold sensitivity；temporal test 只用于最终报告。

### 研究亮点

- **四分支单头动态风险建模**：static、local、global 与 z3M early-response branch 分别学习背景、当前决策态、累积病程和 3M 早期反应，再由单一 hazard head 输出下一时间窗复发风险。
- **3M 表征不是硬拼特征**：z3M 作为独立分支进入模型，并由 `time_sigmoid` gate 调节；`Start_Time < 3M` 时 z3M 嵌入和 mask 均为 0，避免未来锚点信息提前进入。
- **面向概率校准、稀有事件排序和临床预警效用的训练目标**：主损失保留 patient-weighted BCE 以维持概率风险估计；hard-negative ranking 与 DCA-inspired soft net-benefit 仅作为小权重辅助正则，弱对齐低复发率场景下的高风险排序和临床报警阈值。
- **患者级 cluster bootstrap 性能不确定性估计**：bootstrap CI 按 `Patient_ID` 聚类抽样，而不是把同一患者的多个 interval 当作完全独立样本。
- **interval-level 与 patient-level 同时汇报**：既报告每个动态窗口的复发风险，也报告 patient-level max-risk warning，方便转化为随访预警策略。
- **模型解释、阈值敏感性和误差分析闭环**：报告包含 calibration、DCA、threshold sensitivity、top-k capture、错题本和 matched training-time branch removal。

## 队列与任务定义

动态任务定义为：给定患者截至 landmark `t` 的全部可得信息，预测 `t -> t+1` 区间是否出现 Normal→Hyper 复发。由于同一患者可贡献多个 at-risk interval，训练和评估均保留患者级分组意识。

## 3M early-response encoder 背景

3M 固定锚点二分类模型提供早期治疗反应证据，但本报告不把 fixed-landmark 结果作为动态模型的最终输出。它只提供一个 z3M 表征，帮助动态模型在 3M 及之后利用早期反应轨道。

## 特征构建与特征选择边界

当前动态复发模型没有启用额外的 `feature_selection_json` 筛选器；配置表中的 `FeatureSelection` 为空。因此，本版模型不应表述为“由 test 后反选变量得到”，也不把 SHAP、分支消融或错题本当作训练前筛选步骤。

特征策略采用更保守的临床建模口径：先由临床先验定义候选变量，再进行 temporal-safe 特征工程，最后按四个信息来源结构化输入模型。当前共使用 `65` 个输入特征：static `16` 个、local `13` 个、global `22` 个、z3M `14` 个。static branch 承载治疗前背景和疾病负荷；local branch 承载当前窗口的决策态；global branch 承载截至 landmark `t` 的累计病程摘要和窗口交互；z3M branch 承载固定 3M 早期反应模型输出的潜在表征，并在 3M 前强制 mask 为 0。

需要区分两个层次：固定 landmark 3M 二分类模型可报告 top25 LGBM / stable selection 作为早期状态识别模型的特征筛选结果；动态复发模型本身则没有再做显式稳定特征筛选。本报告中的 SHAP、matched training-time branch removal 和 error casebook 均属于 post-hoc explanation / audit，用于解释和审计模型行为，不参与模型训练、阈值选择、校准拟合或特征筛选。

## 训练目标：概率校准、稀有事件排序与临床预警效用

我们设计了一个面向区间级复发预警的临床对齐复合目标函数。该目标保留患者加权二元交叉熵以维持风险概率估计，加入难负样本排序项以改善低复发率场景下的稀有事件排序，并加入小权重、受决策曲线启发的软净获益项，使训练目标弱对齐临床预警阈值。

`L = L_patient-weighted BCE + lambda_r L_hard-rank + lambda_nb L_soft net benefit`

| 组件 | 工程含义 | 医学解释 |
| --- | --- | --- |
| patient-weighted BCE | 按患者加权的二分类交叉熵 | 避免随访更密集的患者在 interval-level 数据中被重复放大，使每位患者对概率学习贡献近似均衡。 |
| hard-negative ranking | 推动阳性 interval 分数高于高分阴性 interval | 在低复发率下优先优化高风险区排序，减少真正复发窗口被高风险假阳性淹没。 |
| soft net-benefit | 可导的 DCA-inspired 辅助项 | 把临床报警阈值附近的假阳性/假阴性权衡弱写入训练目标；DCA 本身仍作为最终临床效用评价。 |

训练目标按照任务的临床结构设计。由于长格式数据中同一患者可贡献多个 at-risk interval，我们使用患者加权 BCE，使每位患者对概率估计目标的贡献近似均衡。考虑到区间级复发率较低，我们加入难负样本排序项，惩罚复发 interval 的分数低于高分非复发 interval，从而改善临床高风险区的排序能力。最后，受 DCA 启发，我们在预设报警阈值附近加入小权重软净获益项，使训练目标弱对齐临床预警效用。

该复合目标不应被理解为替代标准概率风险建模。相反，BCE 被保留以维持概率校准，排序项和软净获益项仅作为小权重辅助正则，分别面向稀有事件预警和临床决策效用。这一设计与动态风险建模中结合概率目标和排序目标的范式一致，也符合临床预测模型中强调校准和决策曲线效用的评价方向。

## 正则化与抗过拟合控制

本模型的抗过拟合策略不是依赖单一强正则，而是由时间安全、患者级权重、辅助目标和模型选择约束共同完成。第一，所有 preprocessing、z3M 可用性和阈值选择都遵守 temporal-safe 规则：temporal test 不参与模型选择、阈值选择、校准拟合或解释层开发；3M 前的 z3M 组件、availability 和 time feature 均强制为 0。

第二，interval-level 长表中同一患者可贡献多个 at-risk interval，因此训练使用 `PatientWeightedBCE=True`，通过患者级 row weight 降低随访次数较多患者对 BCE 概率学习目标的重复放大。最终报告的不确定性估计也采用 `Patient_ID` cluster bootstrap，而不是把 interval 当作完全独立样本。

第三，训练目标中的辅助正则保持小权重：`RankLossWeight=0.1` 用于改善低复发率下的高风险区排序；`NetBenefitLossWeight=0.01`、`ClinicalThreshold=0.2`、`NetBenefitTemperature=0.7` 用于在临床报警阈值附近弱对齐 soft net-benefit。BCE 仍是概率建模主干，ranking 与 soft net-benefit 不替代概率风险学习。

第四，模型选择采用 development-only 约束：`MixedTrainWeight=0.3`、`MixedValWeight=1.0`、`MixedTestWeight=0.0`，且 `DisableTestSelection=True`。学习率调度为 `LRScheduler=plateau`，监控 `selected_score`，best epoch 为 `11`。当前最终报告没有启用 AP loss、LibAUC、z3M auxiliary loss、input/branch gate L1；训练历史中 `mixup_samples=0`，因此不把数据增强写作主模型贡献。公开 artifacts 中未保留最终 run 的 dropout、weight decay 或 branch-drop 数值，本报告不补写这些未确认配置。

## 泄漏控制检查

- 阈值、模型选择、校准拟合不使用 temporal test。
- `MixedTestWeight = 0` 且 `DisableTestSelection = True`。
- `Start_Time < 3M` 的 interval 中 z3M 嵌入、availability 和 time feature 均应为 0。
- train z3M 使用 OOF / train-only 产物；validation 使用 fit-context；test 使用最终 fit+val encoder 产物。

## 局限性

- 动态 interval 同一患者内相关，因此所有 CI 使用 Patient_ID cluster bootstrap，但样本量仍限制了小亚组稳定性。
- z3M branch 当前使用离线 3M 表征；真正 end-to-end pretrain-then-finetune 仍是下一版结构优化方向。
- 当前主模型未做动态复发任务的显式 train-only 稳定特征筛选；本版选择的是结构化临床候选变量与 post-hoc 可解释审计。后续可把 stable feature selection 作为单独消融，而不能使用 temporal test 反选变量。
- Temporal test 是严格时间外推，但仍属于单中心回顾性验证，外部验证可进一步增强证据等级。
