# RAI / Graves / Dynamic Medical ML Q2+ Literature Pack

目标：围绕本项目三模块 RAI 风险预测框架，整理 30 篇二区以上或高质量医学 AI / 统计方法相关论文。

范围：
- Graves/RAI 疗效、复发、NHRH、non-remission、TRAb/早期反应。
- Landmark dynamic prediction、纵向 biomarker、校准、DCA、TRIPOD+AI/PROBAST+AI、低事件率 PR-AUC。
- 与本项目相似的临床机器学习风险分层文章。

产物：
- `summaries/`：每篇独立中文总结。
- `tables/paper_summary_table.csv`：30 篇总表。
- `tables/search_log.csv`：检索记录。
- `tables/screening_decisions.csv`：筛选记录。
- `tables/journal_quartile_evidence.csv`：期刊 Q2+ 证据来源与人工核验提示。
- `tables/open_access_sources.csv`：开放获取 PDF / landing page 链接与本地文件线索。
- `30_paper_summary_table.md`：可直接阅读的 30 篇总表。
- `thematic_synthesis.md`：按 RAI 直接证据、landmark 方法、评价规范、相似医学 ML 主题综合。
- `sources/`：API/search 原始结果。

注意：Q2+ 以 JCR/Scimago/期刊公认分区线索为目标；无法实时验证分区时，在总表中标记 `QuartileEvidence=needs_manual_check`。
